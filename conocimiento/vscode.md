CLAVES: visual studio code

Para abrir una carpeta en Visual Studio Code: menú Archivo (File) > Abrir carpeta (Open Folder), o el botón Open Folder del panel Explorador cuando no hay carpeta abierta. Atajo: Ctrl+K Ctrl+O.

Para guardar: Archivo > Guardar, atajo Ctrl+S.

Para abrir la terminal: menú Terminal > Nueva terminal, atajo Ctrl+`.

El aviso amarillo de Restricted Mode se resuelve con el botón Manage o Trust.
