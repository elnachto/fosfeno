# Escritorio de Windows

Referencia de uso; no demuestra que una acción se haya realizado. Solo se carga en las ventanas del escritorio.

Para crear una carpeta en el escritorio, enfocar primero su superficie o lista de iconos observada. Usar TECLA ctrl+shift+n, volver a observar el campo de nombre, ESCRIBIR el nombre solicitado y TECLA enter. Confirmar que la carpeta con ese nombre aparece en el escritorio; no confundir crear con abrir una carpeta existente. No repetir el atajo si el campo de nombre ya está abierto.
